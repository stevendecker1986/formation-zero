# Individual training experience

Phase F exposes one authenticated consumer path: request → Phase D construction → Phase E independent validation → server delivery decision → immutable workout snapshot. The web and Expo clients render only the consumer-safe snapshot returned by this path. A client-supplied validation status, entitlement, prescribed dose, arbitrary replacement, readiness score, training load, or program phase is rejected by strict schemas or ignored in favor of server state.

The overview shows objective, authorized duration, sections, prescribed dose/rest, equipment, public rationale, warnings through safe status text, and recovery lines when present. Exercise detail uses approved knowledge fields for production content. If no approved image exists, text remains complete and the UI says so. Synthetic demonstrations carry a persistent non-production label and deliberately contain no invented production coaching or media.

Production requests remain unavailable until real content, rules, template, and an authorized Phase E policy satisfy the existing gates. A rejected or stale prescription never creates a workout session.
