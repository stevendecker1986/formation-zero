# Explicit alternatives

Phase B's exact-version REGRESSION, PROGRESSION, SUBSTITUTION, LOW_IMPACT, NO_EQUIPMENT and LIMITED_SPACE edges are available to the constructor. Requests may explicitly require a regression, progression or substitution from a source version in scope. At least one exact eligible target for each request must appear in the mandatory composition. Target selection remains subordinate to Phase C and required template slots. There is no inferred progression chain or recursive fallback.

A blocked source may identify an explicit eligible alternative; the source itself never reappears. Missing/blocked targets fail NO_SAFE_PRESCRIPTION. Targets outside candidate scope are never silently fetched or admitted. Ordinary slot matching provides the documented alternative mechanism for equipment, restriction, space and supervision exclusions: match the same reviewed objective/section/movement/capability/tag requirements using a candidate and dose surviving Phase C. This matching is not represented as an authored progression relationship.

Production relationships are loaded from immutable Phase B links; clients cannot forge them. Synthetic fixtures exercise equipment-loss substitution, progression, regression and blocked targets. Real B2 relationships do not confer publication eligibility.
