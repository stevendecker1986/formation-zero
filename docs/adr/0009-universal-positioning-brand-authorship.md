# 0009 — Universal positioning, canonical brand and authorship separation

Status: Accepted. Date: 2026-09-04. Authority: v1.0-PLAN Amendment 001, preserved in AMENDMENT_001_DIRECTIVE.txt. Applies after completed Phase A and before Phase B.

## Context

Formation Zero is a universal human-performance platform. Publicly releasable Marine Corps human-performance doctrine is a major foundational source, not the audience boundary. Phase A's blue/green shell styling was provisional and conflicts with the newly authoritative branding board. No approved vector or font files were supplied.

## Decision

Record universal positioning and future editorial requirements in PRODUCT_POSITIONING.md. Keep source, authorship, qualifications, technical/safety/specialty review and rights distinct; founder ISSA credentials are owner-stated future metadata, not account fields, rights grants or endorsement. No new content/editorial schema.

Preserve canonical raster board without alteration. Use text identification until approved standalone master artwork is supplied through the documented asset contract. Never redraw the logo. Centralize provisional semantic tokens in the existing UI package, share values with native, and use system fonts without redistributing font files. Apply only shell and existing account-control presentation. Follow DESIGN_SYSTEM.md for broad imagery, accessibility and anti-drift rules.

## Consequences

No auth/security, account data, migration, entitlement, permission or commercial-gate changes. No fitness behavior, onboarding, hierarchy, content registry or Phase B implementation. All tiers share visual quality. Run existing regression checks, new token-contrast checks, visual review and actual hosted CI. Future palette, font and vector approvals can replace centralized presentation assets without redesigning the architecture.
