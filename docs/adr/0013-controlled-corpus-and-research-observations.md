# ADR 0013: Controlled B2 corpus and research observations

Status: accepted for the authorized Phase B2 scope.

Use immutable corpus membership keyed by a checked-in import identifier, linked to the initial knowledge version and entity. Existing CMS edits create subsequent immutable versions of that entity. An idempotent operator import rejects changed input for an existing key; it never overwrites editorial work. Synthetic fixtures are outside membership. All imported records use the existing schema, reference validation and transactional audit path.

The import principal is disabled and has no credentials, editorial grants or publication permissions. It identifies machine-assisted population, not a human professional. Import is a local/server operator command, never an unauthenticated HTTP action. No approval events are created. Candidate states remain DISCOVERED/INGESTED pending normal editorial submission and real review.

Source currency observations store the research date, official locator, scope and limitations. They are not professional verification and do not change the existing derived verification state. A current educational article is not controlling policy. Changes and partially superseded sections are recorded together. Article citations support stated principle notes, not certification of every original exercise instruction or score.

B2 expressly requires TECHNICAL, POLICY, EDITORIAL and RIGHTS for official policy. Official provenance now requires the union of those types and existing prerequisites; exercise/recovery retain SAFETY. This conservative superset prevents registry classification from weakening official-policy review. ADR 0012's supporting verification and independent approver rules remain in force.

Candidate demand and formation scores are provisional editorial classifications, not measurements or prescription logic. Their per-record rationale must be reviewed. Original text rights remain UNKNOWN pending an actual rights decision; source text and future media receive no blanket government-domain clearance. No production media is imported.

Authenticated corpus export excludes people, qualifications, review comments and account identifiers. It exposes content and aggregate review counts only. Export is an editorial inspection artifact, not public distribution or publication.
